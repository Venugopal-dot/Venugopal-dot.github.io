# Venugopal Reddy — .NET Developer Portfolio

A responsive, dark-themed, static portfolio built with HTML, CSS, and JavaScript. It can be hosted for free with GitHub Pages.

## Files
- `index.html` — page content
- `styles.css` — responsive dark theme
- `script.js` — mobile navigation and current year

## Before publishing
1. Review experience dates and descriptions carefully.
2. Add your actual employer names, job titles, and verified employment dates in the Experience section.
3. Add a real resume PDF if you want a resume download link. No download button is included until a file is provided.
4. Add repository links and screenshots for projects you are able to share publicly.
5. Confirm project descriptions are accurate and do not disclose confidential client information.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `Venugopal-dot.github.io` (if your GitHub username is exactly `Venugopal-dot`). If that repository name is unavailable, create another repository such as `dotnet-portfolio`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site. For a user site, the URL is normally `https://Venugopal-dot.github.io/`; for a project site, it is normally `https://Venugopal-dot.github.io/dotnet-portfolio/`.
6. Test the URL on mobile and desktop before adding it to job applications.
